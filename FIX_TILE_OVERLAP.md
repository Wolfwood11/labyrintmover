# 🔧 Исправление наложения тайлов

## ❌ Проблема

Тайлы накладывались друг на друга, потому что мы размещали их в одних и тех же координатах сетки, но Unity позиционирует их в мировых координатах без учета размера тайлов.

## 🔍 Причина

При размере тайла 128px объекты размещались в координатах (0,0), (1,1), (2,2) и т.д., но физически занимали гораздо больше места, что приводило к наложению.

## ✅ Решение

### 1. Масштабирование позиций
Добавлено масштабирование позиций в соответствии с размером тайла:
```csharp
float worldX = pos.x * (tileSize / 100f); // Конвертируем в мировые координаты
float worldY = pos.y * (tileSize / 100f);
```

### 2. Обновлен RoundToCell
Метод `RoundToCell` в `LevelManager` теперь учитывает масштабирование:
```csharp
float scale = gridConfig != null ? gridConfig.TileSize / 100f : 1f;
int cellX = Mathf.RoundToInt(position.x / scale);
int cellY = Mathf.RoundToInt(position.y / scale);
```

## 🎯 Результат

Теперь тайлы правильно позиционируются:
- ✅ **Нет наложений** - каждый тайл занимает свое место
- ✅ **Правильное масштабирование** - позиции соответствуют размеру тайлов
- ✅ **Корректное чтение позиций** - LevelManager правильно интерпретирует координаты
- ✅ **Работает для всех размеров** - от 16px до 128px
