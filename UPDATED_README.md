# A→B: Переставь и Дойди - Обновленный Прототип

## 🎮 Обзор

Мобильная головоломка "A→B: Переставь и Дойди" - это пазл на сетке с перемещением блоков и бесплатным ходом персонажа. Цель: дойти из точки A в точку B, переставляя подвижные блоки среди неподвижных препятствий.

## ✨ Ключевые особенности

### 🎯 Игровая механика
- **Система энергии**: Стоимость хода зависит от размера блока и расстояния до персонажа
- **Объединение блоков**: При столкновении блоки объединяются в bounding box
- **Бесплатное движение персонажа**: Персонаж двигается бесплатно по проложенному пути
- **Система отмены**: Возможность отменить последний ход

### 🧮 Формула энергии
```
S = w*h (площадь блока)
d = manhattan(character, nearestCell(block))
cost_cell = (Ksize * S) * (1 + Kdist * d)
```

### 🎨 UI/UX
- **Превью стоимости**: Показывает количество шагов, изменение расстояния и стоимость
- **Подсказки**: "Подойди ближе — будет дешевле"
- **Пинч-зум и перетаскивание камеры**
- **Система обучения** (3-4 шага)

## 🚀 Использование

### Генерация уровней в редакторе

1. Добавьте `LevelGeneratorComponent` на сцену
2. Настройте параметры генерации:
   - Размеры поля (Width, Height)
   - Плотность статических препятствий (StaticDensity)
   - Размеры и количество блоков
   - Целевые параметры сложности
3. Нажмите "Сгенерировать уровень"
4. При успешной генерации нажмите "Применить к сцене"

### Настройка сложности

Согласно ТЗ, уровни классифицируются как:
- **Easy**: Hmin ≤ 6 и Emin ≤ 12
- **Medium**: 7–12 или Emin 13–25  
- **Hard**: >12 или Emin > 25

### Система обучения

Обучение автоматически запускается для новых игроков и включает:
1. **Добро пожаловать** - Объяснение цели игры
2. **Двигай блоки** - Как перемещать блоки свайпами
3. **Объединяй блоки** - Механика объединения при столкновении
4. **Экономь энергию** - Важность расстояния до персонажа
5. **Достигни цели** - Завершение уровня
