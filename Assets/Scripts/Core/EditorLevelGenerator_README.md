# 🎮 Editor Level Generator

Генератор уровней для редактора Unity с ограничением попыток и удобным интерфейсом.

## 🚀 Быстрый старт

### 1. Создание генератора

**Вариант A: Через меню**
1. Откройте `Tools → LabyrinthMover → Create Level Generator`
2. В сцене появится GameObject `LevelGenerator`

**Вариант B: Вручную**
1. Создайте пустой GameObject
2. Добавьте компонент `EditorLevelGenerator`

### 2. Настройка параметров

В Inspector настройте:
- **Max Attempts**: Максимум попыток генерации (по умолчанию: 100)
- **Level Width/Height**: Размер уровня (по умолчанию: 20x20)
- **Difficulty**: Сложность (Easy/Medium/Hard)
- **Generate On Start**: Автогенерация при запуске (рекомендуется: false)

### 3. Генерация уровня

**В режиме Play:**
1. Нажмите кнопку `🎮 Сгенерировать уровень`
2. Или используйте быстрые кнопки: `🟢 Easy`, `🟡 Medium`, `🔴 Hard`

## 🎯 Особенности

### ✅ Гарантированная проходимость
- Генератор пытается создать проходимый уровень до 100 раз
- Если не удается за 100 попыток, применяется последний сгенерированный уровень

### 🔄 Умная генерация
- Каждая попытка использует разные параметры
- Автоматическая проверка проходимости через решатель
- Подробное логирование процесса

### 🎨 Удобный интерфейс
- Кнопки в Inspector для быстрого доступа
- Информационная панель с текущим статусом
- Возможность остановки генерации

### 📊 Статистика
- Отображение количества попыток
- Статистика сгенерированного уровня
- Оценка сложности и энергии

## 🛠️ Настройки сложности

### Easy (Легкий)
- Статических препятствий: 10%
- Блоков: 5
- Размеры блоков: 1x1, 2x1, 1x2
- Целевые ходы: 8
- Целевая энергия: 20

### Medium (Средний)
- Статических препятствий: 15%
- Блоков: 8
- Размеры блоков: 1x1, 2x1, 1x2, 2x2, 3x1
- Целевые ходы: 15
- Целевая энергия: 40

### Hard (Сложный)
- Статических препятствий: 20%
- Блоков: 12
- Размеры блоков: 1x1, 2x1, 1x2, 2x2, 3x1, 1x3, 3x2
- Целевые ходы: 25
- Целевая энергия: 70

## ⚠️ Важные замечания

1. **Генерация работает только в режиме Play**
2. **Не ставьте `Generate On Start = true`** - это может замедлить запуск
3. **Используйте кнопку "Остановить"** если генерация затянулась
4. **Проверьте логи** для диагностики проблем

## 🔧 Расширение функциональности

Для добавления новых сложностей или параметров:

1. Добавьте новый enum в `LevelDifficulty`
2. Обновите методы `Get*ForDifficulty()` в `EditorLevelGenerator`
3. Добавьте новые кнопки в `EditorLevelGeneratorEditor`

## 🐛 Решение проблем

### Генерация не работает
- **ВАЖНО**: Генерация работает только в режиме редактора (НЕ в Play mode)
- Используйте меню `LabyrinthMover > Генератор уровней` для доступа к генератору
- Проверьте, что все компоненты назначены

### Уровень не генерируется за 100 попыток
- Уменьшите сложность
- Увеличьте размер уровня
- Проверьте параметры генерации

### Ошибки компиляции
- Убедитесь, что все using директивы добавлены
- Проверьте, что все классы находятся в правильных namespace
