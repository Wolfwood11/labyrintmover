## 🚀 Как использовать:

### 1. Создание генератора
```
Tools → LabyrinthMover → Create Level Generator
```

### 2. Настройка параметров
- **Max Attempts**: 100 (максимум попыток)
- **Level Size**: 20x20 (размер уровня)
- **Difficulty**: Medium (сложность)
- **Generate On Start**: false (не генерировать автоматически)

### 3. Генерация уровня
1. **Запустите игру** (режим Play)
2. **Нажмите кнопку** `🎮 Сгенерировать уровень`
3. **Или используйте быстрые кнопки**: `🟢 Easy`, `🟡 Medium`, `🔴 Hard`

## 🎯 Особенности:

- ✅ **Гарантированная проходимость** - генерирует до 100 попыток
- ✅ **Умная остановка** - если не удается, применяет последний результат
- ✅ **Удобный интерфейс** - кнопки в Inspector
- ✅ **Подробные логи** - отслеживание процесса генерации
- ✅ **Настраиваемые параметры** - размер, сложность, попытки

## 🧪 Тестирование:

Добавлен `EditorLevelGeneratorTest` компонент для тестирования:
- Автоматически находит генератор в сцене
- Предоставляет контекстные меню для тестирования
- Выводит диагностическую информацию

## ⚠️ Важно:

1. **Генерация работает только в режиме Play**
2. **Не ставьте `Generate On Start = true`** - замедлит запуск
3. **Используйте кнопку "Остановить"** если генерация затянулась
4. **Проверяйте логи** для диагностики проблем
